Política de privacidade

O MeMimei ainda está em fase inicial de desenvolvimento. Esta página reúne um resumo provisório do tratamento de dados pessoais e será substituída por um texto completo antes da abertura pública da plataforma.

Dados que coletamos

Dados de cadastro do anfitrião (nome, e-mail) e, quando informados voluntariamente pelo convidado, nome e mensagem associados a uma contribuição.

Como usamos os dados

Os dados são usados exclusivamente para operar a plataforma: exibir eventos, processar contribuições e permitir que o anfitrião acompanhe seu evento. Não vendemos dados pessoais a terceiros.

Dados sensíveis

Não armazenamos dados bancários ou credenciais de pagamento. Essas informações são tratadas diretamente pelo provedor de pagamentos integrado à plataforma.
